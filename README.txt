【公開方法】
このフォルダ内の index.html、thanks、assets をGitHubリポジトリ直下へアップロードしてください。

Cloudflare Pages設定
Framework preset: None
Build command: 空欄
Build output directory: .
Root directory: 空欄（初期設定のまま）

GitHub Pages設定
Settings → Pages → Deploy from a branch
Branch: main
Folder: / (root)

フォームの入力内容は保存されず、送信後にサンクスページへ遷移します。
